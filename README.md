# Pocket-Hornet-0_5---Paintball-Event-POS-ANALYSE
Exklusives CASH-POS-System für die Green Hornets Landshut: Super schnell und mega zuverlässig, auch ohne stabiles Internet! Es ist ideal für Paintball-Events und Team-Finanzen. Features: GuV-Analyse, Teamverwaltung, flexible Zahlungen (Bar/interne Buchung). Es hilft bei Kassenführung, Rechnungen und Bilanzen. Privatnutzung ohne USt und Datev etc
